## Important Honesty Notes

- Clerk may hash passwords internally, but Pravaah does not implement password hashing.
- Clerk may issue tokens, but Pravaah integrates and verifies Clerk-authenticated requests rather than issuing its own JWTs.
- Clerk may provide third-party authentication, but provider configuration is not stored as repository code evidence.
- Deterministic no-show scoring is not LLM API integration, prompt engineering, structured output, RAG, or agent behavior.
- PostgreSQL relations do not count as MongoDB schema modeling or MongoDB CRUD.
- Vite SPA deployment does not count as server-side rendering.
- Test files are evidence that tests exist; they are not evidence of current passing test output unless test results are recorded.
